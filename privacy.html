プライバシーポリシー

アプリ「気象予報士試験 合格対策」（以下「本アプリ」）／制定日：2026年9月27日／改定日：2026年10月11日（有償版「Pro」とiCloudでの記録の共有に合わせて改定）

集める情報

本アプリは、氏名・メールアドレス・位置情報・端末の識別子・利用状況などの個人情報や利用データを収集しません。アカウント登録もありません。アクセス解析ツール、広告、トラッキングも使用していません。

ただし、有償版「Pro」の機能を使ったときは、その機能を動かすために必要な情報だけを送ります（下の「Pro の機能で送る情報」）。

学習記録の保存

問題の定着度、過去問の得点、学習した日、学習プラン、設定などの学習記録は、お使いの端末の中に保存されます。

設定の「iCloud で共有する」がオンのときは、同じ Apple ID でサインインしている iPhone・iPad で記録をそろえるために、学習記録をお客さま自身の iCloud（Apple のサービス）にも保存します。iCloud に置かれた記録は、開発者を含むほかの人は見られません。オフにすると、端末の中だけに保存します。

Pro の機能で送る情報

有償版「Pro」の次の機能を使ったときだけ、開発者が用意した中継サーバー（Cloudflare Workers を使用）を通して、次の情報を送ります。

  • AIに質問：入力した質問の文、それまでの会話、質問のもとになった問題・用語・解説の文。中継サーバーから Anthropic（AI「Claude」の提供元）に送り、答えを受け取ります。質問の難しさを判定するため、質問の文を TypeSafe AI（判定用のAI「Jev」の提供元）にも送ることがあります。
  • AI採点：撮影・選択した答案の写真と、その回の解答例のPDF（端末に取り込んだもの）。中継サーバーから Anthropic に送り、採点結果を受け取ります。
  • 解説動画：動画の画像を中継サーバーから読み込みます。
  • 加入の確認：上の機能を使うたびに、App Store で購入したサブスクリプションの取引番号を送り、中継サーバーが Apple（App Store Server API）に加入状況を問い合わせます。お名前やお支払い方法は、開発者には届きません。

中継サーバーは、質問・会話・答案の写真を保存しません（AIに渡して答えを返すだけです）。中継サーバーに残るのは、加入状況の確認結果（30分間）と、月ごとの利用回数（取引番号ごと、約40日間）だけです。

送った内容は、Anthropic と TypeSafe AI のそれぞれの方針に従って扱われます。どちらも、送った内容をAIの学習に使わないことを方針としていますが、安全のために一定期間保存されることがあります。詳しくは Anthropic のプライバシーポリシー、TypeSafe AI のプライバシーポリシーをご覧ください。

答案の写真に、お名前などの個人の情報が写らないようにしてください。

購入について

Pro の購入・解約・お支払いは、すべて Apple の App Store で行われます。お支払いの情報は開発者には届きません。

そのほかの通信

  • 「公式サイトから問題PDFを取り込む」を押したとき：一般財団法人 気象業務支援センターの公式サイトから、過去問のPDFをお使いの端末に直接ダウンロードします。このとき開発者のサーバーは経由しません。
  • 「公式サイトを開く」を押したとき：同センターのウェブサイトを表示します。

通知

リマインド通知は、端末の中で時刻を予約して表示するものです。通知のために情報を外部へ送ることはありません。

変更とお問い合わせ

このポリシーを変更する場合は、このページでお知らせします。お問い合わせはお問い合わせフォーム（サポートページ）からお願いします。お問い合わせの際にご記入いただいたメールアドレスは、返信のためだけに使います。
